# WuKongClient 6.0.1 Beta 1 — Smart Auto Feeder

This beta brings together the Client Evolution milestone and a new optional background eating mode.

## Highlights

- Unified module interface with master switches, module search, persistent favorites and individual configurations.
- Dynamic Zoom, refined HUD Studio controls, themes and profile management.
- Smart Inventory, Enchantment Info+ and Trade Calculator.
- **New: Background Auto Feeder.** Consume food from inventory in singleplayer without switching the selected hotbar slot or starting a hand-use animation.

The existing Standard Auto Eat mode remains available and is the default. Background mode is singleplayer-only; it does not automatically switch modes on external servers.

## Requirements

Minecraft 26.3 · Fabric Loader 0.20.1+ · Fabric API 0.166.2+26.3 · Java 25.

## Installation

Download the regular `wukong-fabric-6.0.1-beta.1.jar`, remove any older WuKongClient JAR from your mods folder and install the new JAR alongside Fabric API. The sources JAR is for development only.

To enable Background mode: **Survival > Auto Eat > Config > Mode > Background (Singleplayer)**.

## Beta status

The project owner has reported successful in-game testing of Background Auto Feeder. Additional regression and fresh-install verification is still pending. Please report issues with reproducible steps and the affected environment.
